NumPy, pandas and Matplotlib: used in the notebooks

NumPy

Arrays and fast math. In tabular RL the Q-table is simply a NumPy array.

Used in the workshop notebooks · preinstalled in Colab

FunctionRole in RL
np.zeros((n_states, n_actions))Create an empty Q-table
np.argmax(Q[s])Greedy action: the column with the highest Q-value
Q[s].max()Best value in the next state, used in the Bellman target
rng = np.random.default_rng(seed)Reproducible random numbers; always fix a seed
rng.random() < epsilonε-greedy coin flip: explore or exploit
rng.integers(n_actions)Pick a random action
np.mean(x), np.std(x)Summarise rewards across episodes or seeds
np.cumprod(1 + returns)Turn weekly returns into a wealth path
Example
import numpy as np

rng = np.random.default_rng(42)
# 12 states x 3 actions (0%, 50%, 100% Apple)
Q = np.zeros((12, 3))
alpha, gamma, epsilon = 0.1, 0.9, 0.1

def choose_action(s):
    if rng.random() < epsilon:    # explore
        return int(rng.integers(3))
    return int(np.argmax(Q[s]))   # exploit

# one Q-learning update for a transition (s, a, r, s_next)
s, r, s_next = 0, 0.01, 4
a = choose_action(s)
Q[s, a] += alpha * (r + gamma * Q[s_next].max() - Q[s, a])
print(Q[s])

Example
import pandas as pd

path = "data/historical_normalized_weekly_stocks_2018_2019.csv"
df = pd.read_csv(path, parse_dates=["date"])
prices = df["AAPL"]
returns = prices.pct_change()          # weekly returns
mom_4w = prices / prices.shift(4) - 1  # past prices only
up_4w = mom_4w > 0                     # state: up or down

split = int(len(df) * 0.7)
train = df.iloc[:split]   # chronological split,
test = df.iloc[split:]    # never shuffled
print(len(train), "training weeks,", len(test), "test weeks")

Matplotlib

Plots: learning curves, wealth paths, allocations and Q-tables.

Example
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)
Q = rng.normal(size=(12, 3))   # stand-in for a learned Q-table

fig, ax = plt.subplots(figsize=(4, 5))
im = ax.imshow(Q, cmap="viridis", aspect="auto")
ax.set(title="Q-table", xlabel="Action", ylabel="State",
       xticks=[0, 1, 2], xticklabels=["0%", "50%", "100%"])
fig.colorbar(im, ax=ax, label="Q-value")
plt.show()

Gymnasium

The standard environment interface: reset, step, repeat. Successor of OpenAI Gym; most RL libraries expect it.

Deep RL · in Colab: !pip install gymnasium

FunctionRole in RL
gym.make("CartPole-v1")Create a ready-made benchmark environment
obs, info = env.reset(seed=42)Start an episode and get the first observation
obs, reward, terminated, truncated, info = env.step(action)Take one action and observe the result
terminated / truncatedEpisode ended naturally / was cut off by a time limit
env.action_space, env.observation_spaceWhat the agent can do and what it sees
env.action_space.sample()A random valid action
class MyEnv(gym.Env)Wrap your own problem, e.g. a portfolio, in the same interface
Example
import gymnasium as gym

env = gym.make("CartPole-v1")
obs, info = env.reset(seed=42)
episode_return, done = 0.0, False

while not done:
    action = env.action_space.sample()   # random policy
    obs, reward, terminated, truncated, info = env.step(action)
    episode_return += reward
    done = terminated or truncated

env.close()
print("Episode return:", episode_return)

PyTorch

Neural networks. A Q-network replaces the Q-table when there are too many states to list.

Deep RL · preinstalled in Colab (free GPU via Runtime → Change runtime type)

FunctionRole in RL
torch.tensor(x, dtype=torch.float32)Turn observations into tensors
nn.Sequential(nn.Linear(...), nn.ReLU(), ...)Build a Q-network: state in, one Q-value per action out
torch.optim.Adam(net.parameters(), lr=1e-3)Optimizer that updates the weights
q.gather(1, a.unsqueeze(1))Pick Q(s, a) for the actions actually taken
with torch.no_grad():Compute targets without tracking gradients
F.smooth_l1_loss(q, target)Huber loss on the TD error (common in DQN)
opt.zero_grad(); loss.backward(); opt.step()One gradient update
Example
import torch
import torch.nn as nn
import torch.nn.functional as F

# state (4 numbers) in, one Q-value per action (2) out
q_net = nn.Sequential(
    nn.Linear(4, 64), nn.ReLU(),
    nn.Linear(64, 2),
)
opt = torch.optim.Adam(q_net.parameters(), lr=1e-3)
gamma = 0.99

# a mini-batch of 32 transitions, random here
s, s_next = torch.randn(32, 4), torch.randn(32, 4)
a = torch.randint(0, 2, (32,))
r, done = torch.randn(32), torch.zeros(32)

# Q(s, a) for the actions taken
q = q_net(s).gather(1, a.unsqueeze(1)).squeeze(1)
# same Bellman target as the Q-table update
# (a real DQN uses a separate target network here)
with torch.no_grad():
    q_next = q_net(s_next).max(dim=1).values
    target = r + gamma * (1 - done) * q_next

loss = F.smooth_l1_loss(q, target)
opt.zero_grad()
loss.backward()
opt.step()
print("loss:", loss.item())

Stable-Baselines3

Tested implementations of DQN, PPO, A2C, SAC and more, built on PyTorch and Gymnasium. Train an agent in a few lines.

Deep RL · in Colab: !pip install stable-baselines3

FunctionRole in RL
DQN("MlpPolicy", env) · PPO(...)Create an agent with a standard network
model.learn(total_timesteps=50_000)Train
model.predict(obs, deterministic=True)Act with the learned policy
evaluate_policy(model, env, n_eval_episodes=10)Mean and std of the episode return
model.save("ppo_cartpole") · PPO.load(...)Store and reload a trained agent
seed=0Fix randomness; compare algorithms over several seeds
Example
import gymnasium as gym
from stable_baselines3 import PPO
from stable_baselines3.common.evaluation import evaluate_policy

env = gym.make("CartPole-v1")
model = PPO("MlpPolicy", env, seed=0, verbose=0)
model.learn(total_timesteps=50_000)

mean, std = evaluate_policy(model, env, n_eval_episodes=10)
print(f"Return: {mean:.1f} ± {std:.1f}")

obs, info = env.reset(seed=1)
action, _ = model.predict(obs, deterministic=True)
