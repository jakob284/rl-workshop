Workshop: Reinforcement Learning

This section establishes the theoretical framework used in the subsequent environment, Q-learning, and training views.

1

Motivation and setting

Sequential decisions under uncertainty

Sequential decision problem

An action changes the immediate outcome and the state in which the next decision is made. The objective must therefore account for current and future rewards.

Planning

If transition and reward functions are known, dynamic programming can compute values and policies directly from the model.

Reinforcement learning

If those functions are unknown, the agent interacts with the environment and learns from observed transition samples.

Objective. Learn a policy that maximizes expected discounted return while resolving the trade-off between exploiting current knowledge and exploring uncertain actions.
2

Markov decision process

The mathematical description of the decision problem

Finite discounted MDP
𝓜 = (𝓢, 𝓐, p, γ)

Here, p(s′,r | s,a) jointly describes the probability of the next state and immediate reward. Equivalently, many texts specify separate transition and reward functions.

𝓢

States

A state contains the information on which a decision is conditioned. The state must be sufficiently informative for the Markov property.

𝓐(s)

Actions

The decisions available in state s. An action affects both the immediate reward and the distribution of the next state.

p(s′,r | s,a)

Transition and reward model

The conditional probability of observing next state s′ and reward r after taking action a in state s.

S₀

Initial state distribution

The distribution from which an episode begins. A finite task can additionally contain absorbing terminal states.

Rₜ₊₁

Reward

Scalar feedback generated by a transition. The reward defines the behaviour encouraged by the model.

γ ∈ [0,1)

Discount factor

Controls the weight assigned to later rewards and ensures a finite return in the continuing discounted setting.

Markov property
P(Sₜ₊₁,Rₜ₊₁ | S₀,A₀,…,Sₜ,Aₜ) = P(Sₜ₊₁,Rₜ₊₁ | Sₜ,Aₜ)

Conditional on the present state and action, the modeled distribution of the next outcome does not depend on the complete earlier history.

3

Trajectory, return, and policy

How behaviour and outcomes are represented

S₀→ A₀ → R₁ →S₁→ A₁ → R₂ →S₂→ ···

Discounted return

Gₜ = Σk=0∞ γᵏRₜ₊ₖ₊₁

The return aggregates rewards from time t onward. A smaller γ places less weight on distant outcomes.

Policy

π(a | s) = P(Aₜ=a | Sₜ=s)

A stochastic policy assigns action probabilities to states. A deterministic policy maps each state to one action.

4

Value functions

Expected return under a specified policy

State value

Vπ(s) = Eπ[Gₜ | Sₜ=s]

Expected return from state s when policy π is followed.

Action value

Qπ(s,a) = Eπ[Gₜ | Sₜ=s,Aₜ=a]

Expected return after taking action a in state s, then following π.

Optimal values. V*(s) = maxa Q*(s,a), and an optimal deterministic policy can be selected through π*(s) ∈ arg maxa Q*(s,a).
5

Bellman equations and dynamic programming

Recursive one-step relationships when the model is known

Bellman expectation equation
Vπ(s) = Σaπ(a|s) Σs′,rp(s′,r|s,a)[r + γVπ(s′)]

Policy evaluation averages over the actions selected by π and all next outcomes permitted by the model.

Bellman optimality equation
Q*(s,a) = Σs′,rp(s′,r|s,a)[r + γ maxa′Q*(s′,a′)]

The value of the first action equals its expected immediate reward plus the discounted value of acting optimally afterwards.

Value iteration

Initialize values arbitrarily and repeatedly apply Bellman optimality backups until the value changes are sufficiently small. Extract the greedy policy afterwards.

Policy iteration

Alternate between evaluating the current policy and improving it through one-step lookahead until the policy is stable.

6

Temporal-difference learning

Replacing model expectations with observed samples

When p(s′,r|s,a) is not supplied, the agent cannot perform the probability-weighted Bellman sum directly. Temporal-difference learning uses an observed transition (St, At, Rt+1, St+1) and bootstraps from the current value estimate.

TD target

Yₜ = Rₜ₊₁ + γ maxa′Q(Sₜ₊₁,a′)

A sampled one-step approximation to the optimal Bellman target.

TD error

δₜ = Yₜ − Q(Sₜ,Aₜ)

The discrepancy between the sampled target and the current estimate.

Q-learning update

Q(Sₜ,Aₜ) ← Q(Sₜ,Aₜ) + αδₜ

The current estimate moves a fraction α toward the sampled target.

Combined Q-learning update
Q(Sₜ,Aₜ) ← Q(Sₜ,Aₜ) + α[Rₜ₊₁ + γ maxa′Q(Sₜ₊₁,a′) − Q(Sₜ,Aₜ)]

Q-learning is off-policy: the update targets the greedy continuation, while the behaviour policy may still explore.

7

Exploration and hyperparameters

Choices governing learning dynamics

α

Learning rate

Determines how strongly a new TD error changes the estimate. A fixed α is useful for demonstration; convergence theory generally requires a suitable decreasing schedule.

γ

Discount factor

Part of the decision objective rather than merely a training setting. It determines the relative importance of future rewards.

ε

Exploration probability

Under ε-greedy behaviour, select a random action with probability ε; otherwise select an action in arg maxa Q(s,a).

Initialization

Q-values may be initialized arbitrarily. The demonstration uses small random values to break ties; zero or optimistic initialization are common alternatives.

Training budget

The number of transitions or episodes determines how much experience is available. Evaluation must be separated from exploratory training.

Environment parameters

Transition noise and reward values define the task. They are not Q-learning hyperparameters, although changing them changes the learned solution.

Convergence conditions. In a finite MDP with bounded rewards, tabular Q-learning converges under standard stochastic-approximation conditions when every state-action pair is visited sufficiently often and the learning rates satisfy appropriate summability conditions. The fixed-rate browser simulation is an instructional demonstration, not a convergence proof.
8

Tabular Q-learning algorithm

Complete procedure used by the demonstration

  1. 1
    Initialize

    Assign an initial value to every accessible Q(s,a).

  2. 2
    Observe and select

    Observe St and choose At using an exploratory behaviour policy such as ε-greedy.

  3. 3
    Interact

    Execute At, then observe Rt+1 and St+1.

  4. 4
    Update

    Compute the TD target and error, then update only Q(St,At).

  5. 5
    Continue

    Repeat until the episode terminates; repeat episodes until the declared training criterion is met.
